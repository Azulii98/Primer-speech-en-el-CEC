# Nissan Guía Conversacional – Contact Center

Herramienta web interactiva desarrollada para apoyar la gestión de leads en el Contact Center de Nissan Colombia.

## Descripción

Esta aplicación guía a los asesores a través de un flujo conversacional estructurado que permite:

- Gestionar prospectos de forma estandarizada.
- Validar autorización de tratamiento de datos (Habeas Data).
- Capturar información del cliente.
- Presentar información de vehículos Nissan.
- Realizar perfilación comercial.
- Generar mensajes listos para enviar.
- Consolidar un resumen final para el asesor comercial.

## Funcionalidades

✅ Flujo guiado de 7 pasos

✅ Mensajes conversacionales automáticos

✅ Gestión de Habeas Data

✅ Captura de datos personales

✅ Catálogo de vehículos Nissan

✅ Perfilación comercial

✅ Seguimiento y reactivación de leads

✅ Resumen automático de la conversación

✅ Diseño responsive para escritorio y móvil

## Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla

## Estructura del flujo

1. Inicio de conversación
2. Validación de Habeas Data
3. Datos personales
4. Información de producto
5. Perfilación comercial
6. Cierre de conversación
7. Reactivación o inactividad

## Publicación en GitHub Pages

1. Crear un repositorio en GitHub.
2. Subir el archivo y nombrarlo `index.html`.
3. Ir a **Settings → Pages**.
4. Seleccionar:
   - Branch: `main`
   - Folder: `/ (root)`
5. Guardar cambios.

La aplicación quedará disponible en:

```

<https://TU-USUARIO.github.io/NOMBRE-REPOSITORIO/>

```

## Uso interno

Esta herramienta está orientada exclusivamente al apoyo operativo de asesores encargados de la atención y seguimiento de clientes interesados en el portafolio Nissan.
